# CRUD Operations Example

This repository now includes a simple Python implementation of CRUD operations.

## Files

- `crud_operations.py`: in-memory CRUD implementation for records with `id`, `name`, and `email`.
- `test_crud_operations.py`: unit tests covering create, read, update, and delete.

## Run

```bash
python3 crud_operations.py
python3 -m unittest -v
```
